# Каталог товаров для seed

Данные и картинки, которыми `app/seed_catalog.py` заполняет каталог.

- `catalog.json`:
  - `categories` — категории «Кухня», «Освещение» и «Сад» с подкатегориями, дополнительно
    к `CATEGORY_TREE` из `app/seed.py`;
  - `products` — товары по подкатегориям: название, slug, описание, варианты с артикулом,
    ценой, остатком и атрибутами (`Цвет`, `Размер`).
- `images/` — по одной картинке на вариант (`<sku>.png`, 800x800, белый фон).

## Запуск

Нужны запущенные контейнеры `db`, `minio` и `backend`, а также применённые миграции
и базовый seed (`python -m app.seed`).

```
docker exec jysk_clone_backend python -m app.seed_catalog
```

Скрипт можно запускать повторно:

- категории, товары и варианты ищутся по slug и артикулу, существующие не меняются;
- картинки загружаются в MinIO под постоянными ключами `products/seed/<sku>.png`;
- фото-заглушки picsum из `app/seed.py` заменяются на картинки из `images/`;
- если у варианта уже есть фото, загруженные через админку, они не трогаются.
