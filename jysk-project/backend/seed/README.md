# Каталог товаров для seed

Данные и картинки, которыми `app/seed_catalog.py` заполняет каталог. Тексты на украинском,
как и весь сайт.

- `catalog.json`:
  - `categories` — 6 категорий с подкатегориями. Slug категорий из `app/seed.py`
    сохранены, названия переведены;
  - `products` — товары по подкатегориям: название, slug, описание, варианты с артикулом,
    ценой, остатком и атрибутами (`Колір`, `Розмір`).
- `images/` — по одной картинке на вариант (`<sku>.png`, 800x800, белый фон).

## Запуск

Нужны запущенные контейнеры `db`, `minio` и `backend`, а также применённые миграции
и базовый seed (`python -m app.seed`).

```
docker exec jysk_clone_backend python -m app.seed_catalog
```

Скрипт можно запускать повторно:

- категории, товары и варианты ищутся по slug и артикулу, дубликаты не создаются;
- названия категорий и товаров, описания и атрибуты вариантов приводятся к `catalog.json`
  (правки этих полей через админку при повторном запуске перезапишутся);
- цены и остатки задаются только при создании варианта и потом не трогаются;
- атрибуты `Цвет` и `Размер` из `app/seed.py` объединяются с `Колір` и `Розмір`;
- картинки загружаются в MinIO под постоянными ключами `products/seed/<sku>.png`;
- фото-заглушки picsum из `app/seed.py` заменяются на картинки из `images/`;
- если у варианта уже есть фото, загруженные через админку, они не трогаются.
