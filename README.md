# Jysk Clone – DevOps Infrastructure

Цей репозиторій містить DevOps-інфраструктуру для проєкту **Jysk Clone**.

Основою є Docker Compose, який дозволяє швидко розгорнути локальне середовище розробки з усіма необхідними сервісами.

---

# Вимоги

Перед початком роботи переконайтеся, що встановлено:

- Docker Desktop (Windows/macOS) або Docker Engine + Docker Compose (Linux)
- Git

---

# Швидкий запуск

## 1. Клонування репозиторію

```bash
git clone https://github.com/v88-crypto/jysk-devops-infra.git
cd jysk-devops-infra
```

## 2. Запуск проєкту

```bash
docker compose -f devops/docker-compose.yml up --build
```

Під час першого запуску Docker автоматично:

- завантажить необхідні образи;
- збере власні Docker-образи;
- створить мережу між контейнерами;
- створить томи для зберігання даних;
- запустить усі сервіси.

---

# Доступ до сервісів

Після успішного запуску будуть доступні:

| Сервіс | Адреса |
|---------|---------|
| Frontend (React) | http://localhost:3000 |
| Backend API (Python/FastAPI) | http://localhost:8000 |
| MySQL Database | localhost:3306 |

---

# Особливості

- 🔄 **Hot Reload** для Frontend і Backend.
- 💾 Дані MySQL зберігаються у Docker Volume `mysql_data`.
- 🐳 Всі сервіси запускаються однією командою.
- 🌐 Контейнери працюють в окремій Docker Network.

---

# Зупинка проєкту

Зупинити контейнери:

```bash
docker compose down
```

Зупинити та видалити всі дані бази:

```bash
docker compose down -v
```

## Команда та внесок учасників

### Дмитро Бережков — Frontend ([@hyKKKy](https://github.com/hyKKKy))

- **Архітектура фронтенду та робота з API.** Переніс проєкт на feature-based структуру. Зробив єдиний HTTP-клієнт з JWT-авторизацією та автоматичним оновленням токена: якщо кілька запитів одночасно отримують 401, токен оновлюється лише один раз. Підключив до бекенду авторизацію, каталог, пошук, кошик, блог, профіль і оформлення замовлення з доставкою, оплатою та скасуванням замовлень.
- **Адмін-панель.** Створив адмінку: товари з завантаженням фото в MinIO, категорії, замовлення, відгуки, блог з чернетками. Додав сід каталогу з реальними товарами та зображеннями.
- **UX-рішення.** Темна тема на CSS-змінних, яка за замовчуванням підлаштовується під тему системи. Варіанти товару (колір, розмір) з окремими фото, ціною та наявністю, а вибраний варіант зберігається в URL. Захист від подвійного оформлення замовлення. Автозаповнення даних покупця з профілю.

### Kostantin Bryzhenyuk — Backend

- **Архітектура бекенду та REST API.** Спроєктував і реалізував увесь бекенд з нуля на FastAPI, SQLAlchemy та MySQL. Розробив схему бази даних на 22 таблиці з міграціями Alembic і REST API для каталогу, кошика, замовлень із доставкою, відгуків, обраного, блогу та адмін-панелі.
- **Авторизація та безпека.** Реалізував реєстрацію та вхід через JWT з access- і refresh-токенами, хешування паролів за допомогою bcrypt, відновлення пароля через email і розмежування доступу до адмін-панелі за ролями користувачів.
- **Логіка замовлень.** Реалізував серверний кошик із перевіркою залишків на складі та оформлення замовлення зі збереженням даних отримувача, способу доставки й суми на момент покупки.
- **Розумний пошук товарів.** Додав виправлення друкарських помилок («матрас» → «Матрац»), обробку запитів у неправильній розкладці («lbdfy» → «Диван») і транслітерації брендів («фалслев» → FALSLEV). Реалізував пропозиції «Можливо, ви мали на увазі…» та підказки під час введення.

### Віталій Лисак — DevOps ([@V88-crypto](https://github.com/V88-crypto))

- **Контейнеризація та локальне середовище.** Налаштував запуск frontend, backend, MySQL і MinIO через Docker Compose. Організував взаємодію сервісів, постійне зберігання даних у Docker volumes і передавання налаштувань через змінні середовища. Підготував `.env.example` та виключив локальний `.env` з Git.
- **Розгортання на AWS.** Підготував сервер AWS EC2 та розгорнув Kubernetes K3s. Налаштував запуск компонентів Hyggy у кластері, доступ до застосунку через Traefik і роботу backend зі сховищем MinIO. Виконував оновлення розгортання та перевіряв стан сервісів.
- **Моніторинг і резервне копіювання.** Налаштував моніторинг за допомогою Prometheus і Grafana та сповіщення про проблеми. Написав скрипти резервного копіювання MySQL і MinIO з передаванням копій до Amazon S3. Автоматизував запуск через cron і перевірив створення та завантаження резервних копій.
- **Документація та перевірка інфраструктури.** Підготував схеми локальної та хмарної архітектури, технічну документацію й інструкції для демонстрації проєкту. Перевіряв доступність сервісів і читання файлів із приватного бакета MinIO через backend. Перед публікацією репозиторію перевірив історію Git на секрети та замінив виявлений пароль локального MinIO.
